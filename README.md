# 星骸回响 · V3.0

**ECHOES OF THE STARFALL · 平面战术机动 × 驾驶员编队 × 肉鸽构筑**

**[进入方舟，开始作战 →](https://kiriusss.github.io/neon-serpent/?v=3.0)**

第七次坍缩之后，城市沉入星骸，夜空再没有一颗星。方舟 07 的接收机，却在三百年后听见了一声：「有人吗？」

你通过驾驶员的意识回响，操纵「衔尾」浮游作战机，在遗迹中夺回旧世界的信号。主机与四枚僚翼组成一支小型编队；你带回的不只是补给，也是某个人未能寄出的告别。

## V3 的作战方式

战场为 **32 × 24** 的连续平面，使用 3D 机体、场景、材质、阴影与局部技能特效呈现。移动仅在 X/Z 平面内进行，松开输入即停止，可以立即反向和斜向移动。

四枚僚翼只承担编队视觉表现。拾取晶体不会使机体变长，自身编队、场地边界和掩体不会扣血；实体掩体会阻挡机体和双方弹丸。实际伤害来自敌人接触、敌方弹丸和带预警的地面攻击。

武器自动射击射程内可见的敌人，弹丸拥有实际飞行时间。巡猎机会追击、射手保持距离、突袭机先预警后冲锋、炮台发射扇形弹幕；首领在生命下降时切换攻击阶段。移动敌机会绕行掩体。

画面强调清晰的敌我轮廓、攻击预警和目标区域。光影由主光、补光、接触阴影与局部效果组成，不使用全屏泛光。菜单由方舟主控、主线作战、共鸣编队、驾驶员档案和回响寻访构成。

## 操作

- `WASD` / `方向键`：平面移动；松开即停，斜向速度与直线一致。
- `Space`：矢量闪避，拥有短暂无敌；最多储备两次，消耗后逐次充能。
- `F`：主驾驶员技能。
- `Q`：释放已配置支援驾驶员的组合支援，冷却 25 秒。
- `Esc` / `P`：暂停与继续。
- `1` / `2` / `3`：在升级界面选择对应技术。
- `C`：切换战术、等轴、俯视镜头；`M`：声音开关。
- 手机：按住四向按钮移动，使用战斗底栏的闪避、技能与支援按钮。

默认战术镜头下，移动方向与屏幕方向一致。镜头切换后，输入仍沿战场 X/Z 轴。切到其他窗口或标签页时会自动暂停。

角色的恢复属性和鸢尾的支援被动会实际加快闪避充能。每次充能限制在 **2～6 秒**；初始砾石为 4.5 秒，编入鸢尾支援后为 4 秒。「相位稳流」还能缩短充能、延长闪避无敌时间，充能最低为 2 秒。

## 四章主线作战

1. **破晓码头 · 机动清剿**：击破三轮、共 21 架敌机。波次间可以回收残骸、调整构筑，并获得少量生命与护盾补充。
2. **失落航线 · 信标护送**：护送承载旧世界坐标的信标走完航线。主机靠近信标 3.6 米以内时才会推进；敌人会攻击信标，信标被击毁即任务失败。
3. **裂隙中枢 · 据点同步**：依次激活三座锚点，在每个区域内累计停留 6 秒。敌机进入同步区域会暂停进度；离开区域不会清空已有进度。清除炮台与增援，为同步争取空间。
4. **寂星之心 · 核心歼灭**：击破「守望者 · 归零」。首领在剩余生命降至 70% 与 35% 时进入新阶段，逐步引入环形弹幕、光束预警与多点轰击。

关卡需依次通关解锁；失败或撤离不解锁后续章节。每次重新作战会重新生成敌人位置和升级候选。观测、标准、侵蚀三种强度可在关卡详情切换。

通关评价包含三个独立条件：完成目标、剩余生命至少 50%、在关卡限定时间内完成。三星时间分别为 **150 / 180 / 180 / 210 秒**。最快时间、最高星级、通关次数与首通奖励领取状态会保留。

## 编队与驾驶员

每支编队由 **1 名主驾驶员 + 最多 2 名不同的支援驾驶员**组成。只有已编入支援位的驾驶员提供被动加成，Q 支援效果也由实际编队决定。主驾驶员使用自己的 F 技能。

- **星烬 / SSR**：高攻击与暴击；主动技能造成近身范围爆发并清除附近敌方弹丸，支援可短暂强化攻击。
- **白曜 / SSR**：高耐久与护盾；主动技能展开护盾、提供短暂无敌并震击附近敌人，支援补充护盾。
- **雾凛 / SR**：主动技能暂时冻结敌机并造成范围伤害；支援提供较短的时停窗口。
- **弦月 / SR**：主动技能对多个敌人释放连续电弧；支援提供范围火力。
- **砾石 / R**：初始伙伴，主动恢复生命并持续修复；支援恢复部分生命。
- **鸢尾 / R**：初始伙伴，主动扩大吸附、补满闪避次数并打击附近敌人；支援提供吸附与闪避补充。

角色档案包含原创立绘、背景故事、技能、支援被动、培养与共鸣信息。主界面可在已拥有的驾驶员之间切换值班角色。

## 局内肉鸽与永久培养

敌人掉落经验晶体，靠近后自动吸附；金色晶体提供更多经验，绿色补给恢复生命。升级会暂停作战，从三个随机异构技术中选择一个。批量获得的经验会保留，并依次处理连续升级。

共有 **15 种**技术，具有不同叠加上限；达到上限的技术不再进入候选。效果包括攻击增强、射速提升、多重弹丸、链式弹射、冻结、再生护盾、暴击、吸附、闪避充能、击杀回血、经验增幅、射程、拾取爆破和技能冷却。

局内技术在下一次行动时重置。角色解锁、同步等级与共鸣保留在本地存档中。

驾驶员同步等级上限 **Lv.20**。首次升级消耗 35 芯片，每级费用增加 15；每升一级，生命与攻击增加基础值的 5%。每阶共鸣额外增加基础值的 6%，并影响防御、暴击等对应属性。移动速度不会随永久养成无限增长。

## 回响寻访与补给

寻访没有付费入口。单抽消耗 **160 星晶**，十连消耗 **1,600 星晶**。新存档拥有砾石、鸢尾，以及 **1,600 星晶和 200 共鸣芯片**。

- 基础概率：**SSR 0.8% / SR 9.2% / R 90%**。
- 连续 **10 抽内至少 SR**；连续 **80 抽内至少 SSR**。
- 没有软保底，新手十连使用相同规则，不额外保证 SSR。
- 单抽、十连和跨次寻访共享计数。获得 SSR 重置两种计数；获得 SR 只重置 SR 计数。
- 同一稀有度的两名驾驶员等概率。触发保底的当次按保底规则结算。
- 每两份重复回响提升一阶共鸣，最高 5 阶。重复 R / SR / SSR 分别返还 **20 / 50 / 100 芯片**，满共鸣后仍返还芯片。

四关每次通关分别获得 **60 / 80 / 100 / 140 星晶**及 **50 / 65 / 80 / 110 芯片**。每关首次通关额外获得 **160 星晶**。失败提供少量补给；倒计时取消、或实际作战不足 15 秒时主动撤离，没有奖励。同一行动编号只能结算一次。

## 存档与运行环境

角色、培养、货币、保底、编队、章节记录和成绩自动保存在当前浏览器。V3 沿用原存储位置，迁移旧版角色、养成、余额与寻访计数，不会重复发放新手补给；新版章节记录从第一章开始。

系统设置支持导出 JSON 存档备份。当前没有网页导入、云端账户或跨设备同步；清除网站数据、更换浏览器或切换网站来源后，原浏览器的进度不会自动随之迁移。

需要支持 **WebGL 2** 的现代浏览器。流畅画质会降低渲染负担，声音可随时关闭。Three.js、立绘、脚本与样式均在项目内，运行时不依赖外部 CDN、在线字体或远程音频。

## 本地运行与验证

安装 Node.js 后，在项目目录执行：

```sh
npm run dev
```

默认地址为 `http://127.0.0.1:4173`；端口占用时自动尝试后续端口。运行所需 Three.js 已随仓库提供。安装开发依赖并验证：

```sh
npm ci
npm test
npm run check
npm run prepare-pages
```

- `dist/engine.js`：连续平面移动、碰撞、弹丸、差异 AI、四类任务、技能与构筑。
- `dist/meta.js`：寻访概率、保底、培养、编队、旧档迁移、关卡解锁与单次结算。
- `dist/main.js`：终端页面、操作输入、暂停、升级选择与作战结果。
- `dist/scene.js`：3D 机体、战场、镜头、阴影与预警效果。
- `dist/assets/`：驾驶员头像与全身立绘。
- `tests/`：规则、数值及页面流程的无浏览器自动化测试。
- `docs/`：GitHub Pages 发布副本。

规则测试覆盖移动停止与反向、斜向归一、掩体阻挡、闪避无敌、弹丸命中、寻路、护送与占点条件、首领阶段、连续升级和结算。数学机器人以两名未培养的初始 R 驾驶员分别完成四关，使用实际移动、技能、敌人 AI 与弹丸逻辑。静态检查验证脚本语法、模块引用和页面控件引用。

本次开发遵照用户要求，不使用 Computer Use 或浏览器自动试玩。自动化检查不代替真实设备的画面、音效、触控手感与兼容性验收，这些由用户实际试玩确认。
