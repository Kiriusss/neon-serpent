# 星骸回响

**ECHOES OF THE STARFALL · 三维机动 × 驾驶员养成 × 肉鸽构筑**

**[进入方舟，开始深潜 →](https://kiriusss.github.io/neon-serpent/)**

群星已坠落。你，是回声。

坍缩将文明折进多层空间。方舟保存着幸存驾驶员的意识回响，却失去了通向旧世界的航路。你将与驾驶员建立神经链接，操纵不断延展的「衔尾机」，回收散落的记忆星骸，在异构体的围猎中穿越折叠遗迹，追寻最后的信号——「寂星之心」。

## 真正的三维活动空间

战场由 **14 × 7 × 14** 个空间格组成，包含七个实际高度层。衔尾机能够沿 X、Y、Z 三个轴向六个方向移动；蛇身、星骸、敌人、障碍、攻击范围和碰撞都拥有三维坐标。

在另一个高度经过同一组 X/Z 坐标，不会撞到那里的蛇身。敌人也会跨层追击；磁吸和攻击依据空间距离生效。连续收集不同高度的星骸，还能获得额外积分与能量。

当前高度切片、层数刻度、地面投影、位置坐标和世界方向标识共同帮助判断深度。画面使用主光、补光、柔和阴影和局部技能特效，关闭全屏泛光，优先呈现清晰的轮廓、材质和危险预警。

## 操作

- `W` / `S`：沿 Z 轴远离 / 靠近；`A` / `D`：沿 X 轴左移 / 右移。
- `Q`：上升一层；`E`：下降一层。之后会继续沿所选方向移动。
- 按住 `Space`：相位穿行，加速并穿过自己的蛇身；消耗能量，松开恢复。
- `F`：释放当前驾驶员的主动技能，受技能冷却限制。
- `C`：切换等轴、正面、俯视视角。
- `Esc`：暂停 / 继续；`Enter`：开始深潜。
- 手机可使用界面中的六向移动、相位与技能按钮。

方向始终沿世界坐标，不随镜头旋转。不能立即向当前移动方向的正后方掉头，可以提前输入两次转弯。

穿越边界会从另一侧返回，但会损伤机体。蛇身和障碍碰撞会造成伤害，部分碰撞还会缩短机体。相位穿行只解除自身碰撞，不免疫边界、障碍或敌人的伤害。生命耗尽后本次深潜结束。

## 一局深潜

1. 在方舟选择驾驶员、培养同步率，并选择「观测 / 深入 / 侵蚀」探索强度。
2. 在立体战场中收集星骸、规避残骸和敌人。武器自动攻击空间射程内的目标，你负责路线、升降、相位和主动技能。
3. 收集与击破提供经验。升级时战斗暂停，从三个随机异构技术中选择一个，继续构筑本局的能力。
4. 清除当前区段的敌人，前往下一区段：**破碎航道 → 失重庭院 → 回声熔炉 → 零界深井 → 寂星之心**。
5. 第五区段出现首领「寂星之心 · NULL」。躲避有预警的空间轰击，击破首领完成深潜；首领低生命时会加快进攻节奏。
6. 战斗结算获得星晶与共鸣芯片，带回方舟唤醒、培养驾驶员，再次出发。

金色星骸提供更高收益，绿色星骸恢复生命，蓝色星骸暂时冻结敌人。连续吞噬和相位状态能够提高积分收益。

## 局内肉鸽构筑

本局可获得 15 种异构技术，拥有不同的叠加上限；已达上限的选项不会再次进入升级候选。

- **火力与弹幕**：攻击提升、自动攻击加速、额外目标、射程扩张。
- **连锁与控制**：链式雷鸣、命中冻结、吞噬爆破、每波时停。
- **生存与续航**：最大生命、再生护盾、击杀回血、相位节能。
- **成长与探索**：暴击强化、经验增幅、三维磁吸。

例如，分形弹幕与链式雷鸣适合清理分散敌群；引力捕获与吞星反应能把收集路线变成攻击路线；再生棱镜与生命回响提高持续作战能力。选择会直接改变攻击、生命、护盾、吸附、能耗或控制效果。

**局内构筑在下一次深潜时重置；驾驶员的解锁、同步等级与共鸣永久保留在本地存档中。**

## 六名驾驶员

- **SSR · 星烬 / 热熵**：高攻击与暴击，主动技能「超新星坍缩」造成范围爆发。她寻找着坍缩之夜那段未完成告别的另一端。
- **SSR · 白曜 / 棱晶**：高生命、防御与初始护盾，「绝对棱域」提供防护与反击窗口。她仍记得最后一道屏障后的微弱心跳。
- **SR · 雾凛 / 时序**：较短技能冷却与快速能量恢复，「零时回廊」冻结敌人。她带着一只永远慢一秒的怀表，追逐停滞的未来。
- **SR · 弦月 / 电弧**：暴击与多目标火力，「群星连奏」攻击附近敌群并强化后续射击。她把失散者的声音编成新的航行坐标。
- **R · 砾石 / 重装**：初始解锁，生命与防御可靠，「战地重整」恢复机体。对他而言，修得好的东西就没有放弃的理由。
- **R · 鸢尾 / 探知**：初始解锁，拾取范围与冲刺续航更强，「星尘牵引」扩大收集能力。她相信散落的记忆里，藏着回家的路。

驾驶员档案提供原创立绘、人物往事、技能与数值预览。角色差异会体现在实战，而不只改变外观。

## 回响寻访与保底

游戏没有付费入口。星晶通过战斗结算获得；新存档赠送 **3200 星晶（20 次寻访）与 200 共鸣芯片**。

- 单次寻访消耗 **160 星晶**；十连消耗 **1600 星晶**。
- 基础稀有度概率：**SSR 3% / SR 17% / R 80%**；每个稀有度内的两名角色等概率。
- 连续 **10 抽内至少获得 SR 或 SSR**。
- 连续 **50 抽内至少获得 SSR**。
- 新存档首次 **10 抽内至少获得 1 名 SSR**；提前抽中 SSR 即完成新手保障，不会在第十抽额外再赠一名。
- 单抽与十连共用同一套计数。获得 SR 或 SSR 重置稀有保底；获得 SSR 同时重置 SSR 保底。
- 已有驾驶员再次出现时，每份重复回响提供一份共鸣进度；每两份提升一阶，最高 **5 阶**。重复 R / SR / SSR 还分别获得 **20 / 50 / 100 共鸣芯片**，满共鸣后仍返还芯片。

上述数字为基础概率；触发保底时，该次寻访按对应保底规则结算。游戏内可查看规则、保底进度与寻访结果，并跳过寻访演出。

## 同步率、共鸣与数值

花费共鸣芯片可提高驾驶员同步等级，上限 **Lv.20**。首次升级消耗 35 芯片，之后每级费用增加 15。

同步等级每升一级，生命与攻击增加该角色基础值的 5%；每阶共鸣额外增加基础值的 6%。防御、暴击、暴击伤害、能量与技能冷却也会受到共鸣或等级的对应加成。移动速度不会随永久养成不断变快。

战斗中的攻击、暴击、防御、护盾和生命会参与实际计算。局内异构技术在驾驶员的永久属性之上进一步生效。

正常战斗结算至少提供 **160 星晶**，并根据积分、击破数、到达区段及通关情况增加星晶和共鸣芯片。倒计时取消，或实际战斗不足10秒时主动撤离，不发放奖励。每次深潜拥有独立编号，同一编号不会重复领取奖励。

## 存档与运行环境

角色、货币、保底、培养进度和成绩保存在当前浏览器的本地存储中。无需登录，没有云端账户或跨设备同步；清除网站数据、更换浏览器或切换网站来源，会影响对原存档的访问。

需要支持 **WebGL 2** 的现代浏览器。画质菜单可以关闭阴影、降低渲染分辨率。首次交互后才启用音频，声音可关闭。

Three.js、驾驶员立绘、样式和脚本均随项目提供；场景几何与电子音效由程序生成。运行时不依赖外部 CDN、在线字体或远程音频。

## 本地运行

安装 Node.js 后，在项目目录执行：

```sh
npm run dev
```

打开终端显示的地址。默认使用 `http://127.0.0.1:4173`，端口被占用时自动尝试后续端口。运行所需的 Three.js 文件已包含在仓库内，不必先安装依赖；如需重新安装开发依赖，可执行 `npm install`。

## 开发、验证与发布

- `dist/`：开发源文件与本地资源。
- `dist/engine.js`：六轴移动、碰撞、敌人、首领与异构升级。
- `dist/meta.js`：驾驶员、寻访保底、养成、存档校验与结算。
- `dist/scene.js`：立体场景、镜头、阴影及局部特效。
- `dist/assets/pilots-atlas.png`：六人驾驶员原创立绘图集。
- `docs/`：GitHub Pages 发布副本。
- `tests/`：不依赖浏览器的自动化规则测试。

```sh
npm ci
npm test
npm run check
npm run prepare-pages
```

规则测试用于验证六轴移动、跨层碰撞、战斗与升级、寻访保底、养成扣费、存档及重复结算；静态检查验证脚本语法、模块引用和页面控件引用。

本次开发遵照用户要求，不使用 Computer Use，也不进行浏览器自动试玩。规则与静态验证不能替代实际设备上的画面、音效、操作手感及兼容性验收，这些项目交由用户亲自试玩。

GitHub Pages 继续使用 `main` 分支的 `/docs` 目录。修改 `dist/` 后运行 `npm run prepare-pages`，将源码与 `docs/` 一并提交推送，发布地址保持不变：

**[https://kiriusss.github.io/neon-serpent/](https://kiriusss.github.io/neon-serpent/)**
