# NEON SERPENT · 霓虹贪吃蛇

**[直接开玩 →](https://kiriusss.github.io/neon-serpent/)**

一个真正用 WebGL 渲染的 3D 霓虹街机。悬浮竞技场、机械蛇身、旋转星门、发光能量核心、吞噬粒子、相位冲刺和原创程序合成音乐。

## 玩法

- **经典竞速**：撞到边界或蛇身结束游戏。
- **无尽穿梭**：从竞技场另一侧穿出，仍需避开蛇身。
- **相位冲刺**：按住空格，速度提升，穿过自身，吞噬得分翻倍；消耗能量，松开恢复。经典模式冲刺仍会撞墙。
- **连续吞噬**：7 秒内再次吃到能量，倍率递增，最高 ×8。
- **三种节奏**：漫游、心跳、失控。每吞噬 5 个能量提升一级。
- **特殊核心**：粉色 +100；金色 +250；蓝色让游戏减速 5 秒。得分叠加连击和冲刺倍率。

## 操作

- `W A S D` 或方向键：转向（可提前输入两次转弯）。
- 按住 `Space`：相位冲刺。
- `Enter`：开始；`Esc` / `P`：暂停或继续。
- `C`：立体 / 俯视视角；`R`：重新开始。
- `M`：声音；`F`：全屏。
- 手机：滑动场景或点击方向键，按住冲刺按钮。

首次开始后才播放声音。离开窗口自动暂停。最好成绩按模式和难度保存在当前浏览器本地。菜单右上角可以切换流畅画质；系统减少动态效果偏好会默认关闭镜头震动和背景旋转。

## 本地运行

安装 Node.js 后，在本目录执行：

```sh
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:4173`；端口被占用时自动使用下一个空闲端口）。Three.js 与所有依赖模块已随项目提供，不需要连接外部 CDN，也不需要安装依赖即可运行。

需要支持 WebGL 2 的现代浏览器。启用硬件加速体验更佳。

## 开发与发布

- `dist/`：源页面、样式、游戏逻辑、场景、音效及 Three.js 运行时。
- `docs/`：GitHub Pages 静态发布目录。
- `tests/`：不依赖浏览器的游戏规则回归测试。

```sh
npm test
npm run check
npm run prepare-pages
```

GitHub Pages 使用 `main` 分支的 `/docs` 目录。修改 `dist` 后运行 `npm run prepare-pages`，将源码与 `docs` 一并提交推送。
